## 🛠️ 工具功能

### 📸 配料表拍照识别
拍下零食包装背面的配料表，自动识别是否含有牛奶成分（乳清粉、酪蛋白、乳固体、乳糖、黄油、奶酪等几十种"马甲词"）。

### 🚦 敏宝能吃什么查询
80+ 常见食物红绿灯分级：🟢 放心吃 / 🟡 谨慎试 / 🔴 避免吃，一查便知。

### 📝 喂养打卡
记录每天加了什么新食物、有没有过敏反应，复诊时给医生看，清清楚楚。

### 📈 生长曲线
记录身高体重，自动生成趋势图，直观了解宝宝生长发育情况。

## 📊 为什么做这个项目？

牛奶蛋白过敏（CMPA）是婴儿期最常见的食物过敏之一，发生率约 **2%–3%**。确诊后需要严格忌口，但市面上的喂养工具大多面向普通宝宝，很少专门针对敏宝家庭的实际需求。

我们的目标：
- ✅ 让每个敏宝妈妈都能轻松读懂配料表
- ✅ 让辅食添加有据可依，不再靠"试错"
- ✅ 让喂养记录不再是一笔糊涂账
- ✅ 所有工具 **完全免费**，不注册、不下载
